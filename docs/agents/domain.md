# Domain Docs

This is a single-context repo.

Before architecture, debugging, or TDD work, read these if they exist:

- `CONTEXT.md`
- `docs/adr/`
- relevant docs under `docs/`

If `CONTEXT.md` or `docs/adr/` does not exist, proceed silently.

`domain-modeling`, `grill-with-docs`, and `improve-codebase-architecture` may create or update domain docs when real terms or decisions are resolved.

Use established project terms from `CONTEXT.md` when present. If an output contradicts an ADR, call that out explicitly.
