# Security Policy

## Supported Versions

This project is early-stage. Security fixes are applied to the latest code on the default branch.

## Reporting a Vulnerability

Please do not open a public issue for security-sensitive reports.

Use GitHub private vulnerability reporting if it is enabled for the repository. If that is not available, contact the repository owner privately and include:

- what you found
- how to reproduce it
- the potential impact
- whether credentials, tokens, cookies, or user data could be exposed

## Current Security Scope

In scope:

- dependency vulnerabilities
- credential or secret exposure
- CSRF, rate-limit, or security-header bypasses
- unexpected data exposure through HTTP routes

Out of scope:

- general feature requests
- non-security bugs without confidentiality, integrity, or availability impact
